# Bienvenue dans Écritoire

Un **classeur** est un simple dossier. Chaque document est un fichier *Markdown* avec un petit en-tête YAML.

- Glissez-déposez les éléments de la barre latérale pour les réordonner.
- ⇧⌘↩ active le **mode focus** ; Échap le quitte. ⇧⌘F cherche dans tout le classeur.
- ⌥⌘I affiche l'inspecteur (titre, synopsis, statut, publication).

> L'ordre manuel est rangé dans un fichier `.order` de chaque dossier.

Les liens [[Personnages]] et [vers le site](https://example.com) sont colorés.
